# SIH Project Instructions

- Follow the existing architecture and approved acquisition configuration autonomously.
- Routine implementation, testing, validation, preprocessing and resumable acquisition may proceed without repeated confirmation when they remain within the approved scope.
- Ask the user before changing data scope, data sources, scientific definitions, thresholds, paid services, credentials or deleting retained data.
- Data scope includes years/dates, provider/model, ensemble members, variables/levels, cycles, leads, temporal resolution, geographic domain, grid resolution, verification/fallback sources and storage ceiling.
- Reuse explicit decisions recorded in project configurations and runbooks. Do not silently substitute a source or scientific definition.
- Report only meaningful milestones, failures and required manual actions; do not request repeated “go on” confirmations.
- Read-only inspection, option discovery and reversible diagnostics may always proceed.
